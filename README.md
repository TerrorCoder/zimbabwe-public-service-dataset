# Zimbabwe Public Service Knowledge & AI Benchmark Dataset

This repository contains a highly structured, machine-readable dataset designed to bridge the public information access gap in Zimbabwe by standardizing public service procedures and translating key service guidance from English into Shona and Ndebele.

The current pilot scope includes 9 records spanning Civil Registry, Deeds Office, ZIMRA, PRAZ, and the Ministry of ICT. In Phase 1, the target is to scale to 150+ records and 750 multilingual QA pairs to support robust retrieval, question-answering, and benchmarking for local AI systems.

## Translation Notes

The Shona and Ndebele string blocks in this repository are currently **draft quality** and are awaiting native-speaker dual-pass review in Phase 1.
