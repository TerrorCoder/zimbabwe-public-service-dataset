This repository contains a highly structured, machine-readable dataset designed to bridge the public information access gap in Zimbabwe by standardizing public service procedures and translating key service guidance from English into Shona and Ndebele.

The dataset includes **20,000 public service procedure records** (`SVC-00001` through `SVC-20000`) spanning all **10 provinces, 60 administrative districts, 32 urban municipalities, 60 rural district councils, and 1,958 administrative wards of Zimbabwe**, backed by **100,000 multilingual QA intent benchmark pairs** across English (`en`), Shona (`sn`), and Ndebele (`nd`).
